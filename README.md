# LCSHierarchyBot

[![LCSHierarchyBot CI](https://github.com/XVIIStarPlatinum/LCSHierarchyBot/actions/workflows/workflow.yml/badge.svg)](https://github.com/XVIIStarPlatinum/LCSHierarchyBot/actions/workflows/workflow.yml)

Телеграм-бот для вашего сообщества: считает баллы за активность участников, присваивает им ранги, показывает профили и
рейтинг, помогает администраторам и убирает неактивных участников.

Эта инструкция написана для человека **без опыта программирования**. Если что-то не получается — не переживайте, просто
напишите разработчику (контакты — в конце файла) и укажите, на каком шаге застряли.

## 1. Что нужно подготовить заранее

Перед тем как начинать, убедитесь, что у вас есть:

- **Компьютер или сервер с Linux**, к которому у вас есть доступ (например, по SSH). В этой инструкции команды даны для
  Ubuntu/Debian — если у вас другая система, некоторые команды установки программ могут отличаться, но всё остальное
  будет одинаковым.
- **Ваша группа в Telegram**, переведённая в режим "супергруппа с темами" (топиками). Если вы не знаете, что это — не
  страшно, ниже есть отдельный шаг, как это включить.
- Немного терпения — настройка займёт около 20-30 минут, но делать это нужно **один раз**.

## Шаг 1. Скачивание бота на сервер

Подключитесь к своему серверу и выполните команду:

```bash
git clone https://github.com/XVIIStarPlatinum/LCSHierarchyBot.git
```

Перейдите в папку с ботом:

```bash
cd LCSHierarchyBot
```

Все дальнейшие команды нужно выполнять, находясь именно в этой папке.

---

## Шаг 2. Установка программ, которые нужны боту

Боту нужен Python (язык программирования, на котором он написан) и `git` (программа, которой мы только что скачали
бота). Если они уже установлены — команда ниже просто ничего не изменит, это безопасно выполнить в любом случае:

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git
```

Проверьте, что Python установился:

```bash
python3 --version
```

Должна появиться версия `3.11` или новее (подойдёт любая версия из диапазона 3.11–3.14).

### Создаём отдельное "окружение" для бота

Это изолированное место, где будут храниться программы, необходимые именно этому боту, — чтобы они не смешивались с
другими программами на сервере. Находясь в папке `LCSHierarchyBot`, выполните:

```bash
python3 -m venv .venv
```

Активируйте его (это нужно делать каждый раз перед запуском бота вручную — но когда мы настроим автозапуск в Шаге 8,
делать это руками больше не понадобится):

```bash
source .venv/bin/activate
```

После этой команды в начале строки терминала появится `(.venv)` — это значит, что окружение активно.

Теперь установите все нужные боту библиотеки одной командой:

```bash
pip install -r requirements.txt
```

Это может занять минуту-две. Если в конце вы видите строки вида `Successfully installed ...` — всё прошло успешно.

## Шаг 3. Создание бота в Telegram

1. Откройте Telegram и напишите **@BotFather** (это официальный бот Telegram для создания других ботов).
2. Отправьте команду `/newbot` и следуйте инструкциям: придумайте имя бота (то, что видят люди) и username (уникальное
   имя, обязательно заканчивается на `bot`, например `LCSCommunityBot`).
3. BotFather выдаст вам **токен** — длинную строку вида `12345678:AaBbCcDdEeFfGgHhIiJj...`. Это пароль от вашего бота —
   никому его не показывайте. Сохраните его, он понадобится в Шаге 6.
4. **Важный шаг, без которого бот не будет работать правильно.** Отправьте BotFather команду `/setprivacy`, выберите
   вашего бота и нажмите **Disable**. Это разрешает боту видеть все сообщения в группе (а не только те, что явно к нему
   обращены) — без этого бот не сможет считать баллы за сообщения участников.

## Шаг 4. Подготовка группы в Telegram

1. Если у вас пока обычная группа — превратите её в **супергруппу с темами (топиками)**: откройте настройки группы →
   "Темы" (Topics) → включите. Если группа уже с темами — пропустите этот пункт.
2. Создайте (или убедитесь, что уже есть) тему **"Основной чат"** — именно в ней бот будет считать баллы за активность.
3. Создайте тему **"ВАЖНОЕ"** — туда бот будет присылать уведомления о новых администраторах, легендах и т.п.
4. Добавьте вашего бота в группу (по username, который вы придумали в Шаге 3).
5. Сделайте бота **администратором** группы. При выдаче прав обязательно включите:
   - **Удаление сообщений** (Delete messages) — нужно для борьбы со спамом.
   - **Блокировка пользователей** (Ban users) — нужно, чтобы бот мог удалять неактивных участников по правилам ранговой
     системы.

   Остальные права можно оставить выключенными — они боту не нужны.

## Шаг 5. Получение всех нужных ID

Боту нужно знать несколько технических номеров (ID): ID вашей группы, ID двух тем и ваш личный ID (как владельца). Все
они — просто числа, их не нужно "придумывать", их нужно "подсмотреть".

### ID группы и ID тем (топиков)

1. Отправьте любое сообщение в теме **"Основной чат"** вашей группы.
2. Откройте в браузере вот такую ссылку, заменив `<ВАШ_ТОКЕН>` на токен из Шага 3 (просто вставьте его вместо
   `<ВАШ_ТОКЕН>`, стрелочные скобки убирайте):

   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```

3. На странице появится текст в формате JSON. Найдите там кусок вида:

   ```
   "chat":{"id":-1002390728252, ... }
   "message_thread_id":1
   ```

   - Число рядом с `"chat":{"id":` (обычно длинное и **отрицательное**, начинается с минуса) — это ваш **CHAT_ID**.
   - Число рядом с `"message_thread_id"` — это **TOPIC_ID** темы "Основной чат".
4. Повторите то же самое, но отправив сообщение в теме **"ВАЖНОЕ"** — так вы получите **TOPIC_IMPORTANT_ID**
   (`message_thread_id` для этой темы). `CHAT_ID` при этом останется тем же самым.

   Если страница по ссылке пустая или там нет нужных сообщений — просто отправьте новое сообщение в нужной теме и
   обновите страницу в браузере.

### Ваш личный ID (владельца)

1. Напишите в Telegram боту **@userinfobot**.
2. Он сразу ответит вам сообщением, где будет строка `Id: 123456789` — это ваш **OWNER_ID**.
3. Также запомните свой **username** в Telegram (то, что после `@` в вашем профиле, без самого `@`) — это будет
   **OWNER_USERNAME**.

## Шаг 6. Настройка файла .env

Все секретные данные и настройки бот хранит в одном файле — `.env`. Находясь в папке `LCSHierarchyBot`, создайте его на
основе примера:

```bash
cp .env.example .env
```

Теперь откройте файл `.env` в текстовом редакторе, например через `nano`:

```bash
nano .env
```

Вы увидите примерно такое содержимое — замените каждое значение на своё (то, что вы собрали в Шагах 3 и 5):

```
TELEGRAM_TOKEN=токен_из_шага_3
CHAT_ID=число_из_шага_5_отрицательное
TOPIC_ID=число_темы_Основной_чат
TOPIC_IMPORTANT_ID=число_темы_ВАЖНОЕ
OWNER_ID=ваш_личный_id
OWNER_USERNAME=ваш_username_без_собачки
BOT_USERNAME=username_бота_без_собачки
DATABASE_PATH=database/hierarchy.db
```

`DATABASE_PATH` можно оставить как есть — это просто путь, где бот будет хранить свою базу данных (баллы, ранги и всё
остальное).

Сохраните файл: в `nano` это `Ctrl+O`, затем `Enter`, затем выход — `Ctrl+X`.

## Шаг 7. Первый запуск (проверка)

Убедитесь, что окружение активно (в начале строки терминала должно быть `(.venv)`; если нет — выполните
`source .venv/bin/activate`), и запустите бота:

```bash
python3 bot.py
```

Если всё настроено верно, в терминале побегут строки логов и среди них будет строка
`=== Bot initialization completed successfully ===` — без слов `CRITICAL` или `ERROR` рядом. Бот в этот момент уже
работает и отвечает в Telegram.

Проверьте вживую:

- Напишите боту в личные сообщения `/start` — должно прийти приветствие.
- Напишите любое сообщение в теме "Основной чат" — через пару секунд команда `/profile` в личке боту должна показать,
  что баллы начислились.

Чтобы остановить этот тестовый запуск, нажмите `Ctrl+C` в терминале.

Это был просто ручной, "тестовый" запуск — он работает только пока открыт терминал. Чтобы бот работал постоянно (в том
числе после перезагрузки сервера), переходите к следующему шагу.

## Шаг 8. Запуск бота "навсегда"

Чтобы бот работал круглосуточно, сам перезапускался при сбоях и запускался автоматически после перезагрузки сервера, мы
настроим его как **системную службу (systemd)** — это стандартный способ на Linux.

### 8.1. Узнайте два значения

Выполните:

```bash
whoami && pwd
```

Первая строка — ваше имя пользователя на сервере, вторая — полный путь до папки с ботом (например,
`/home/ivan/LCSHierarchyBot`). Запомните оба значения — они понадобятся в следующем пункте.

### 8.2. Создайте файл службы

```bash
sudo nano /etc/systemd/system/lcs-hierarchy-bot.service
```

Вставьте туда следующее, заменив `ВАШЕ_ИМЯ` на результат `whoami`, а `ПУТЬ_ДО_ПАПКИ` — на результат `pwd` из пункта 8.1:

```ini
[Unit]
Description = LCS Hierarchy Bot
After = network-online.target
Wants = network-online.target

[Service]
Type = simple
User = ВАШЕ_ИМЯ
WorkingDirectory = ПУТЬ_ДО_ПАПКИ
ExecStart = ПУТЬ_ДО_ПАПКИ/.venv/bin/python3 ПУТЬ_ДО_ПАПКИ/bot.py
Restart = always
RestartSec = 5

[Install]
WantedBy = multi-user.target
```

Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`).

### 8.3. Включите и запустите службу

```bash
sudo systemctl daemon-reload
sudo systemctl enable lcs-hierarchy-bot
sudo systemctl start lcs-hierarchy-bot
```

Проверьте, что бот запустился и работает:

```bash
sudo systemctl status lcs-hierarchy-bot
```

Если видите зелёную надпись `active (running)` — всё хорошо, бот работает в фоне и продолжит работать даже после
перезагрузки сервера.

С этого момента запускать `python3 bot.py` вручную больше не нужно — если понадобится перезапустить или остановить бота,
используйте команды из раздела [Обслуживание бота](#обслуживание-бота).

## Как пользоваться ботом

У бота три роли:

- **Владелец** (вы) — все возможности бота без ограничений.
- **Администратор** — назначается вами, помогает управлять сообществом.
- **Участник** — обычный человек в группе, зарабатывает баллы и ранги.

Все команды бота работают **только в личных сообщениях с ботом**, не в самой группе.

### Основные команды (доступны всем)

| Команда    | Что делает                                               |
|------------|----------------------------------------------------------|
| `/start`   | Приветствие и краткая инструкция (текст зависит от роли) |
| `/profile` | Показывает ваш профиль: ранг, баллы, место в рейтинге    |
| `/top`     | Показывает топ-100 участников по баллам                  |

Помимо команд, в личных сообщениях с ботом есть кнопки — "👤 Мой профиль", "🏆 Топ" и так далее. Они делают то же самое,
что и команды, просто в один тап.

### Команды для администраторов и владельца

| Команда                                   | Что делает                                                                     |
|-------------------------------------------|--------------------------------------------------------------------------------|
| `/add @username <баллы> причина: <текст>` | Добавляет или убирает баллы участнику                                          |
| `/admins`                                 | Показывает список администраторов                                              |
| `/reset @username`                        | Сбрасывает таймер неактивности участнику (чтобы его не удалили за бездействие) |
| `/@username`                              | Показывает профиль указанного участника                                        |

### Команды только для владельца

| Команда                 | Что делает                           |
|-------------------------|--------------------------------------|
| `/legend @username`     | Присваивает участнику ранг "Легенда" |
| `/unlegend @username`   | Снимает ранг "Легенда"               |
| `/setadmin @username`   | Назначает участника администратором  |
| `/unsetadmin @username` | Снимает права администратора         |

### Как устроены ранги

Участники получают баллы за сообщения, загрузку музыки и реакции **в теме "Основной чат"**. Чем больше баллов — тем выше
ранг, и тем больше привилегий (отправка фото/видео, стикеров, закрепление сообщений и т.д.). Полный список рангов и
порогов баллов бот показывает в приветственном сообщении (`/start`).

Новые участники, которые не написали `/start` боту в личку в течение 24 часов, автоматически удаляются из группы — это
защита от ботов и случайных людей. Об этом их предупреждает сообщение при входе в группу.

## Обслуживание бота

### Посмотреть, что бот сейчас делает (логи)

```bash
sudo journalctl -u lcs-hierarchy-bot -f
```

Это покажет "живую" ленту того, что бот делает прямо сейчас (нажмите `Ctrl+C`, чтобы выйти из просмотра — сам бот при
этом продолжит работать). Более подробные логи по каждой части бота отдельно также сохраняются в папке `logs/` внутри
папки с ботом (файл `logs/bot.log` — это общий лог).

### Перезапустить бота

Если бот "завис" или нужно применить обновления настроек в `.env`:

```bash
sudo systemctl restart lcs-hierarchy-bot
```

### Остановить бота

```bash
sudo systemctl stop lcs-hierarchy-bot
```

### Обновить код бота (когда разработчик присылает исправления)

```bash
cd LCSHierarchyBot
git pull
source .venv/bin/activate
pip install -r requirements.txt
sudo systemctl restart lcs-hierarchy-bot
```

### Сделать резервную копию данных

Все баллы, ранги и профили хранятся в одном файле. Периодически (например, раз в неделю) стоит сохранять его копию в
надёжное место:

```bash
cp database/hierarchy.db ~/hierarchy_backup_$(date +%Y-%m-%d).db
```

Эта команда создаст копию с сегодняшней датой в названии, например `hierarchy_backup_2026-08-11.db`, в вашей домашней
папке.

## Частые проблемы

**Бот не отвечает вообще, ни на команды, ни на сообщения в группе**

- Проверьте, что служба работает: `sudo systemctl status lcs-hierarchy-bot`. Если там написано `failed` или `inactive` —
  посмотрите логи (`sudo journalctl -u lcs-hierarchy-bot -n 50`) и проверьте `.env` — скорее всего, там опечатка в
  токене или одном из ID.

**Бот отвечает в личных сообщениях, но не считает баллы за сообщения в группе**

- Проверьте, что вы отключили режим приватности через `/setprivacy` у @BotFather (Шаг 3, пункт 4).
- Проверьте, что вы пишете именно в теме "Основной чат", а не в другой теме или в общем чате без темы.

**Бот не может удалить неактивного участника или удалить спам-сообщение**

- Проверьте права бота в группе — у него должны быть включены "Удаление сообщений" и "Блокировка пользователей" (Шаг 4,
  пункт 5).

**После перезагрузки сервера бот не запустился сам**

- Убедитесь, что вы выполнили `sudo systemctl enable lcs-hierarchy-bot` (Шаг 8.3) — именно эта команда включает
  автозапуск.

**Я запутался/что-то пошло не так, а в этом списке решения нет**

- Скопируйте последние строки из `sudo journalctl -u lcs-hierarchy-bot -n 100` и отправьте разработчику — это сильно
  ускорит решение проблемы.
